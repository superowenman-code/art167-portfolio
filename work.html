Projects

We All Scream For

This project was cover art for my porfolio comic project having a skull shaped ice cream on the floor. The art style was inspired by a game called Slay the Spire, using its blocky shaped rendering as inspiration

This poster itself took weeks, with multiple iterations made.

Shattered Vision

This project was to make a poster for my brand. A crystal creature on a crystal planet, based off of my story that I want to eventually turn into an IP.

Neon Mind

This project was to test out a new drawing app along with playing around with colors that I usually dont use.

Movie Poster

This project was Five Night's at Freddys Movie Poster concept made in class to see how detailed I can get with my abilitys.

Process

  1. Plan the layout / create thumbnail sketches
  2. Work on line art
  3. Apply colors, shading, and highlights
  4. Rendering and finishing touches
